# Editorial Diagram Design Guide (44 Types)

## Core Capabilities
1. Standalone HTML + SVG: Zero external renderers, no server dependencies.
2. No Shadows / No Mermaid Slop: Crisp editorial lines, high legibility, curated color palettes.
3. 44 Diagram Types:
   - Architecture & Systems: Architecture Delta, Current-State IT, C4, Layer Stack, Medallion, Deployment.
   - Flow & Logic: Flowchart, Sequence, State Machine, Data Flow, Process Map, Sankey.
   - Strategy & Taxonomy: Wardley Map, Mind Map, Decision Tree, Ecosystem Flywheel, Venn, Quadrant.
   - Timelines & Roadmaps: Timeline, Gantt, Swimlane, User Journey, Milestone Roadmap.

## Visual Standards
- Canvas: Responsive SVG with viewBox.
- Background: Dark or clean white with subtle 1px borders.
- Nodes & Boxes: Rounded rects (rx=6), clean typography (Inter / Roboto), distinct semantic colors.
