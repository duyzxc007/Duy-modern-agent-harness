# Master Visual Presentation & Diagramming Hub

End-to-end visual communication combining native editable PowerPoint decks with editorial-grade architectural diagrams.

## 1. Native PowerPoint Generation (PPT Master)
- Generates native shapes (DrawingML), real vector lines, formatted text frames, and editable tables.
- Supports template registration, custom company branding, speaker notes, and automated audio narration (via `edge-tts`).
- Dependencies: `python-pptx` (installed), `XlsxWriter` (installed).

## 2. Editorial Diagram Design (44 Visual Types)
- Produces self-contained HTML + SVG diagrams.
- Clean typography, high contrast, zero external dependencies, no Mermaid shadows or blurred graphics.
- Covers 44 diagram types: Architecture, C4, Sequence, Flowchart, Timeline, State Machine, Data Flow, Swimlane, Sankey, Radar, etc.

## 3. Workflows & Resources
Progressively disclosed in `workflows/`:
- `workflows/pptx_mastery.md` — Slide deck creation, shape geometry, speaker notes, template workflow.
- `workflows/editorial_diagrams.md` — 44 diagram design patterns, color palettes, SVG layout rules.
- Pre-packaged templates in `templates/`, scripts in `scripts/`, references in `references/`.
